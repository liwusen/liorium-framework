# session-log

用户说「记一下」「写进记忆」「归档这次会话」「session log」时，按下面步骤做。

## 步骤

1. 先 `read memories://sessions` 看今天有没有同名文件（没这个目录就跳过）。
2. 没有就用 `write` 新建；已有就用 `edit` 追加，**不要覆盖**旧内容：

   ```
   write memories://sessions/2026-11-04.md
   ```

3. 正文用这个结构，条目要短、要是事实（能被以后检索到）：

   ```markdown
   # 2026-11-04

   ## 14:20 会话结论

   - 结论：……（一句话）
   - 依据：……（文件 / 命令 / 工具输出）
   - 待办：……（没有就写"无"）
   ```

4. 写完后回读一次 `read memories://sessions/2026-11-04.md` 确认，再用一句话
   告诉用户"存到哪了"（给 `memories://` 路径，不要只说"存好了"）。

## 边界

- 只记**长期有用**的事实（结论、决定、偏好、待办），不要记对话过程。
- 记忆库路径就是标题：一条事实一个文件比一个大文件更好检索。
- 敏感信息（密钥、令牌、口令）一律不写入记忆。
